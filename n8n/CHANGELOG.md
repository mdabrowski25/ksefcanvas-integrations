# Changelog

## 0.1.0

- KSeF Canvas node: drafts (create, get, get many, validate, preview PDF, issue in KSeF with an optional wait for the result), invoices (status, get many, download PDF, XML or UPO), clients and products.
- KSeF Canvas Trigger: invoice accepted in KSeF and invoice rejected by KSeF, through signed webhooks registered with the API.
